# Service Account Setup

Administration -> Users and access -> Service accounts -> Add service account

  Display name: claude-code
  Role:         Viewer

Add service account token -> no expiration -> copy the glsa_ value into .env at
the repo root, which the dev shell sources and .mcp.json expands:

  GRAFANA_SERVICE_ACCOUNT_TOKEN=glsa_...

Then `direnv reload` and restart Claude Code.

# API Equivalent

Admin credentials are the grafana-admin Secret in
secrets/kube-prometheus-stack.secret.yaml.

curl -sSu "$ADMIN_USER:$ADMIN_PASSWORD" \
  -H 'Content-Type: application/json' \
  -d '{"name": "claude-code", "role": "Viewer", "isDisabled": false}' \
  https://grafana.vonarx.online/api/serviceaccounts

curl -sSu "$ADMIN_USER:$ADMIN_PASSWORD" \
  -H 'Content-Type: application/json' \
  -d '{"name": "claude-code"}' \
  https://grafana.vonarx.online/api/serviceaccounts/<id>/tokens

# Permissions

Viewer grants datasources:query but not datasources:read at datasources:* scope.
If list_datasources comes back empty, add the fixed:datasources:reader role to
the account.
